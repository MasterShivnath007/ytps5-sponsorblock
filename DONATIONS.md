# Donation and sponsorship

There are two rails, both optional:

1. **GitHub Sponsors** — recurring or one-time, international, built into the
   repository. <https://github.com/sponsors/MasterShivnath007>
2. **Razorpay** — one-time Indian payments (UPI, cards, netbanking).
   <https://rzp.io/rzp/gkf8SP9>

The in-app **Support master_shivnath** QR points to the GitHub Sponsors page.
The repository Sponsor button is configured in `.github/FUNDING.yml`.

## What sponsorship supports

- Firmware and app-build maintenance.
- Test hardware and release builds.
- Documentation, issue triage, and the occasional 4–5 video startup-delay
  investigation.
- Keeping the public GPL-3.0 code and release assets available.

## What it does not buy

- It does not remove the GPL-3.0 license or make the public code private.
- It does not add telemetry, ads, or a mandatory account.
- It does not change the safety rules: `PPSA01650`/`PPSA01651` (Y2JB apps) remain
  unsupported for patching.

Sponsorship is a thank-you, not a subscription to the software. The public
build stays free. If you need an invoice or a payment method other than these
two, open an issue.
