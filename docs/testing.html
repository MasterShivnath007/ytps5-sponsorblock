Test procedure

Testing ytps5

Test target: PS5 firmware 8.20, Y2JB + Relapse, etaHEN with FTP on 2121 and elfldr on 9021, clean app PPSA01652 by default; any PPSA0165x build of 01.000.003 works.

PPSA01650/PPSA01651 are Y2JB daily drivers. They are refused by default; set allow_y2jb=1 only if a second app handles Y2JB. Keep the default test on PPSA01652.

Build

export PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk
export LLVM_CONFIG=/opt/homebrew/opt/llvm@18/bin/llvm-config
make minify
make installer

build/ytps5-installer.elf is the single file to upload.

Install

  1. Upload ytps5-installer.elf in Payload Manager (or place it in the local payloads folder) and run it.
  2. Confirm the toast “ytps5: waiting for PPSA01652” (or your configured title).
  3. Open PPSA01652 (or the configured title).
  4. Expect a short freeze, then “ytps5: hook installed” and “N script(s) injected”.

Checklist

  • App launches to the home screen.
  • No in-player ads play.
  • Feed/hero sponsored cards are gone.
  • Settings → ytps5 Settings opens.
  • Ad Block / SponsorBlock / category toggles work.
  • Support master_shivnath opens the QR panel.
  • SponsorBlock finds and skips a known segment.
  • Close and reopen the app; it is patched automatically without rerunning the installer.
  • Run the installer on a clean boot; it starts the proxy and injector.
  • Config: /data/ytps5-sponsorblock/config.txt is created with comments.
  • Config: changing patch_title and restarting the injector targets the new app.
  • Config: a Y2JB title with allow_y2jb=0 falls back to PPSA01652.

Logs

python3 tools/ytps5.py logs --host <PS5_IP> --save

Or read from the console:

  • /data/ytps5-sponsorblock/relay.log
  • /data/ytps5-sponsorblock/injector.log
  • /data/ytps5-sponsorblock/proxy_server.log

Expected injector stages include app suspended, kernel_mprotect, installed target, resumed, and calls=... injected=....

Failure notes

  • Stuck launch screen: reboot and rerun the installer. Verify the app is the tested build and that you did not try to patch a Y2JB app.
  • No SponsorBlock: check that the proxy is listening (curl http://<PS5_IP>:4040/ping from the same network should return []).
  • No update toast: confirm version.json exists on main.
